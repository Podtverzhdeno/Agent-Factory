# ADR-0001 — one canonical spec system

Date: 2026-10-26
Status: Accepted (SDD architecture only).

## Context
Both GitHub Spec Kit and OpenSpec are requested; full parallel installation would generate duplicate source-of-truth requirements and drift.

## Decision
OpenSpec is authoritative for requirements and incremental deltas; Spec Kit constitution, clarified acceptance, plans, analysis/checklists and convergence are adopted as techniques. The engineering constitution is at .specify/memory/constitution.md; implementation tasks at openspec/changes/*/tasks.md.

## Alternatives
Two parallel SDD trees (rejected due to drift); only Spec Kit (more ceremony for tiny iterative changes); only informal markdown (insufficient gates).

## Consequences
No canonical feature requirements outside OpenSpec. Archive only when implementation and tests are verifiably accepted. Use replaceable adapter ports for runtime (including experimental Pi Durable) and optimizer (GEPARD/Soup). Change decisions through ADR and reviewed PR.
